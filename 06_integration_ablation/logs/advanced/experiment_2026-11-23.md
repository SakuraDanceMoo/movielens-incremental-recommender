# 阶段六 历史记忆与残差校正实验

日期为2026-11-23，时区Asia/Hong_Kong。使用D盘共享环境，原始混合数据31,900,204条，12个既有文件保持原字节。近期候选条件记忆思想做小型评分回归改编，完整方法和论文边界见[方法说明](../../../docs/advanced_method.md)。

## 核心结果与评价口径

固定本轮开发选择后，同一77,469位审计用户上，原ALS为 **0.899173945**，上一轮Qwen/MF/ALS融合为 **0.876419442**，本轮为 **0.854792328**。相对上一轮降低 **2.468%**，相对原ALS降低 **4.936%**。旧减新RMSE的配对bootstrap 95%区间为[0.020133, 0.023061]，1000次用户重采样，条件于已固定模型。

本轮开发五折OOF为 **0.856428205**。386,982条外层留出合并结果为 **0.856100973**，其中开发行用OOF，审计行用五模型均值。上一轮0.875872445是原外层纯验证选模成绩，两轮第二层监督不同，严格比较优先使用审计的同一批用户。旧项目模型曾用全体外层留出选模，因此审计仅对本轮新校正保留，仍需全新隐藏测试。

## 实际训练和配置

本轮训练8个神经基础配置，再按开发最佳轮次全量重训8个。候选注意力读取最近16条严格过去记录；强正则MF、时间偏置MF和截断SVD++均保留。批量16,384，AdamW，种子20261123。完整入模75特征，排除任意坐标方向的32个隐向量维度。

最终选中 `calibration_v2_d8_no_semantics`，57列，CatBoost深度8、1200轮、学习率0.035、叶正则25、子采样0.8、8线程。五折只在309,513位开发用户内训练，每条开发预测未使用本条标签拟合校正器。没有审计eval_set或早停。

## 匹配消融与负结果

| 配置 | 开发OOF RMSE | 审计RMSE |
| --- | ---: | ---: |
| 完整75特征 | 0.856989082 | 0.855337944 |
| 移除历史特征 | 0.862061381 | 0.860365149 |
| 移除本轮神经特征 | 0.861518947 | 0.859835520 |
| 移除额外语义特征 | 0.856428205 | 0.854792328 |

历史和本轮神经特征有用；额外语义特征移除后开发成绩更好，最终采用该简化方案。语义移除仍保留旧Qwen分支，不是对整个系统删除Qwen。树模型的特征组消融不能当作单个注意力算子的独立因果证明。

加大MF维度没有超过较小的时间MF。训练损失下降而开发误差回升的实际曲线保留，不延长训练冒充提升。早期66维pilot使用过中途的时间MF预测快照，与最终特征不完全相同，仅保留为探索记录，不进入正式比较。

额外树种子仅检验校正层随机性，全部新基础网络仍是一个种子。原来Qwen轮的两种子结果不等同于本轮完整流程重复实验。
