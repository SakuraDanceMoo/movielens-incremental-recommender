# 2026-11-23 混合数据 Transformer 评分回归实验

时间口径为 Asia/Hong_Kong，日期2026-11-23。该扩展归属阶段六，不增加阶段七。

## 做了什么

将用户数据迁入仓库的 `data/raw/hybrid/`，十二个原文件迁移前后 SHA-256 一致，清单为根目录 `data/hybrid_manifest.json`。原文件没有写入Git，旧预测文件未覆盖。

复现原ALS时间留出基线，31,513,222条拟合评分、386,982条验证评分，RMSE0.8974749141752105，与旧结果误差小于1e-7。使用官方 Qwen3-Embedding-0.6B 的冻结语义特征，编码175,170部电影，128维、最长64token，耗时147.94秒；权重LFS SHA-256与上游一致。

训练四类特征token的单层4头Transformer，使用SDPA、SwiGLU、监督MSE和因子正则。八种结构各用两种子，均在全量拟合集遍历4轮、batch16384。两种子为20261123和20261124。为最佳随机初始化方案补齐去语义、去注意力、纯MF对照。

## 实测结果

模型组件消融详见 `ablation.csv`，逐轮真实损失与验证指标位于 `history_*_validation_seed*.json`，模型和种子选择位于 `selection.json`。

| 方法 | 两种子平均验证RMSE | 样本标准差 |
| --- | ---: | ---: |
| ALS初始化 Qwen Transformer | 0.890360075 | 0.000558025 |
| 随机初始化 Qwen Transformer | 0.882582675 | 0.001241610 |
| 随机初始化、移除语义 | 0.882827211 | 0.000163272 |
| 随机初始化、用MLP替换注意力 | 0.885451716 | 0.001778900 |
| 随机初始化纯MF | 0.877738604 | 0.000031938 |
| 最终三分支融合 | **0.876024980** | **0.000215716** |

除最后一行，表中神经方案均已与原ALS做验证选权融合，不能误读成纯神经分支成绩；纯神经数值在每轮 `raw_neural_rmse` 中保留。

最终组合以0.05步长搜索231种凸权重，每个种子独立选择；均得到Transformer0.25、MF0.55、ALS0.20。种子20261123验证RMSE为0.875872445，较原ALS下降2.407%。按所选轮次，用全部31,900,204条评分重训Transformer4轮、MF3轮，并使用全量ALS因子生成100,000条预测。

融合分支消融见 `ensemble_ablation.csv`，去Transformer、去MF、去ALS的两种子平均RMSE为0.877738604、0.882582675、0.877636621。冻结Qwen语义的独立收益很小且随种子变号，不能声称语义本身稳定改善评分。仅说“新模型优于原ALS”也会掩盖强MF对照，因此同时报告MF与完整融合。

## 验证与复现

环境为Python3.11.16、PyTorch2.8.0+cu128、CUDA12.8、RTX4070Ti12GB，Spark单机local[*]。依赖与权重位于仓库上一级 `.venv`，详见 `environment.json` 与 `encoder_manifest.json`。

五项小规模行为测试覆盖语义开关、注意力替换、缺失因子回退和融合边界，入口为 `scripts/test_transformer.py`。全数据独立复核入口为 `scripts/verify_transformer.py`，核对迁移哈希、16次模型预测RMSE、最终凸组合、十万行输出及测试键的顺序。

最终文件为 `data/raw/hybrid/test_pairs_predictions_transformer.csv`，四列为userId、movieId、timestamp、predicted_rating。输出SHA-256为 `b1443aa7135444a2bb4cf7103730b694f856cbb1a9c56210c78447b41e46d174`。

## 评价边界与下一步

这是同一验证集上的轮次、结构、权重和种子选择结果，存在选模乐观偏差。测试表没有评分标签，真实测试RMSE不可计算。当前模型为冻结内容编码器加小型评分Transformer，没有端到端微调大语言模型，也不是HLLM或HSTU的完整复现。

后续应划分独立的校准集与最终评测集，增加种子数量，验证更长用户历史与语义特征在真实和合成来源中的差异，并在多节点环境另行评估系统扩展性。
