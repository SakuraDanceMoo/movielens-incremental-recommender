# Qwen3 语义与特征 Transformer 评分优化

该工作纳入既有阶段六，不新建阶段七。输入采用用户提供的混合评分数据，所有实测结果在同一份 386,982 条时间留出评分上比较。原始文件迁入本仓库 `data/raw/hybrid/` 并以 Git 忽略，迁移前后的 SHA-256 记录在 `data/hybrid_manifest.json`。

## 方法选择与资料边界

截至本次实验采用的公开版本，Qwen3-Embedding 官方系列提供冻结文本编码和可裁剪的 Matryoshka 向量。选择 0.6B 版本适配 RTX 4070 Ti 12GB 显存。预训练权重、依赖、模型缓存全部放在共享环境 `D:\AgentProject2026\.venv`。模型精确 revision 与文件哈希见阶段六 `logs/transformer/encoder_manifest.json`。

项目借鉴 HLLM 的内容编码与推荐模块分离思路，使用 Qwen3 编码电影标题及类型，再将用户因子、电影因子、语义、类型和年份组织成四类 feature token，交给一个小型监督 Transformer。注意力通过 PyTorch SDPA 实现，前馈层为 SwiGLU。这里没有复现 HLLM 的双大模型序列架构，也没有复现 HSTU 的生成式序列转导或万亿参数模型。不得把本地 RMSE 结果表述为论文的复现结论或当前所有推荐模型的最优结果。

## 评分与训练

预训练文本编码器冻结，标题中的合成流水号前缀移除，文本中不含用户评分。取最后有效 token 的前128维并作 L2 归一化。训练部分使用32维用户与电影向量、评分偏置、4头自注意力及残差评分头，优化 MSE 与因子正则。ALS 初始化采用与原实验一致的 rank16、8轮、正则0.1。另保留随机初始化对照。

神经模型与固定原 ALS 做凸融合，权重在0至1、步长0.05的候选中选择；最终评分裁剪到0.5至5.0。每组实验遍历全部31,513,222条拟合数据4轮，批量16,384，随机种子为20261123与20261124。不同组件共享独立的批次生成器，以保证同一个种子的批次顺序相同。

## 消融与评价限制

先比较完整模型、移除语义、以MLP替代自注意力、移除ALS初始化、仅因子微调五组。发现随机初始化更优后，再为随机初始化方案补做移除语义、移除自注意力、仅因子微调三个匹配对照，合计八种结构、十六次完整训练。各组均报告两种子均值与样本标准差，且同时保留单独神经预测和融合后的验证曲线。不得将融合增益全部归因于大模型或注意力。

轮次、融合权重、结构和最终种子均根据该验证集选择，因此报告的是开发过程的验证成绩，存在选模乐观偏差。配对 bootstrap 区间仅描述选定模型在这批验证用户上的条件差异，不包含选模不确定性。`test_pairs.csv` 无真实评分，隐藏测试 RMSE 不可计算。

## 最终三分支组合

单独 Transformer 与 ALS 融合不及随机初始化的 MF 对照，因此最终同时保留两种神经分支与原 ALS。以0.05为步长，在每个种子的231个非负且和为1的三元权重中选择。两个种子均选择 Transformer 0.25、MF 0.55、ALS 0.20。

验证 RMSE 分别为0.875872445与0.876177514，均值0.876024980、样本标准差0.000215716。选定模型相对原 ALS 的0.897474914下降2.407%。再去掉Transformer、MF或ALS，并重新搜索剩余分支权重，得到的两种子平均 RMSE 分别为0.877738604、0.882582675、0.877636621。

这表明分支互补在该验证协议下有效。语义特征本身在两种子的独立消融中贡献方向不一致，当前实验不能证明冻结大模型语义带来稳定的独立收益。所有曲线、参数选择和负结果均保留在 `06_integration_ablation/logs/transformer/`。
