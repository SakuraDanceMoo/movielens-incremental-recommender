# 阶段六进阶评分回归方法与评价协议

本轮在既有阶段六中改进混合数据评分预测，保留原ALS、上一轮Qwen/Transformer融合及全部负结果。不增加阶段七，原表不改写。结果入口为 `06_integration_ablation/logs/advanced/audit_evaluation.json`，预测清单为同目录 `prediction_manifest.json`。

## 方法与近期研究的关系

2026年公开的TransX将序列编码、行为记忆与候选条件融合分开，LWR让候选相关工作区读取持久历史证据。本地在RTX 4070 Ti 12GB条件下借鉴候选条件历史读取，做显式评分回归改编。它是最近16条历史上的小型交叉注意力网络，不是上述工业系统或长序列大模型的完整复现，也没有跨公开数据集比较，因此不宣称全球SOTA。论文资料来自arXiv一手元数据，保存在 `docs/advanced_sources.json`。

## 基础评分器

1. 强正则MF对照。比较64维三个正则系数0.003、0.03、0.08，以及128维正则0.04，保留用户、电影、来源偏置。AdamW无额外weight decay，学习率0.002，第4轮起每轮乘0.85，批量16,384，梯度范数裁剪5。
2. 时间偏置MF。加入来源与年份分箱偏置、电影与五年分箱偏置，正则0.03。
3. 截断因果SVD++参考。最近16条已观测电影向量按历史长度平方根归一化后加入用户表示，不等同于原论文全历史SVD++。
4. 候选条件历史注意力。32维、4头SDPA，query来自用户和目标电影，key/value来自历史电影、评分和位置。以门控混合注意力记忆和隐式历史汇聚，并保留近期评分残差。比较有无时间偏置。

每轮完整遍历31,513,222条拟合评分，仅使用309,513位开发用户选择轮次。后加入的实验采用连续三轮无改善早停，最初探索保留其实际完整日志。开发成绩不显示或使用本轮预留审计指标。

## 严格历史前缀

使用用户和时间戳的64位排序键，对查询执行左侧searchsorted。历史仅来自同一用户、严格早于查询时间的拟合事件，同一时间戳全部排除。训练、验证、全量重训和测试均使用相同规则。每个非padding token的时间关系已在构建时断言，计数见 `temporal_history_fit.json` 与 `temporal_history_full.json`。

需要区分历史前缀与离线协同训练。用户、电影整体统计和基础因子使用允许的整个拟合表，其他用户的较晚记录也可能参与电影表示；不能将整个系统描述成全局滚动时间回测。测试前缀的平均长度低于验证前缀，仍存在分布变化。

## 残差校正

原融合分数作为基准，CatBoost预测真实评分减原融合分数的残差。特征包括用户与电影计数、收缩均值与标准差、年份、类型偏好、最近评分汇总、候选电影与历史的相似度、既有与新增基础模型分数、MF向量范数和偏置。构造107列候选特征，但移除32列原始隐向量坐标以避免全量重训后的任意坐标方向影响，完整入模75列。额外Qwen特征的移除配置为57列。所有输入均不包含查询真实评分。

比较树深6/700轮与树深8/1200轮，学习率0.035、L2叶正则25、Bernoulli子采样0.8、CPU8线程。固定轮次训练，不用审计标签早停。校正器训练的标签来自开发留出用户，这与仅训练基础模型的第一轮协议不同，不能隐去这层监督。

开发用户按混合用户哈希分五折。每折仅用其他四折开发标签拟合校正器，为该折生成折外预测。每位开发用户的标签不进入为自己预测的校正器。五个模型对77,469位审计用户和测试配对取均值。基础模型不在开发五折内重新训练，因为它们始终只拟合原来的31,513,222条评分。

## 冻结、消融与边界

开发OOF选定模型名称和参数并写入 `frozen_selection.json` 后，才读取一次审计RMSE。本轮没有根据审计反馈再修改结构。历史项目曾在整个386,982条外层留出上调参，所以上述审计只对本轮校正器保留，不能称作项目历史完全独立的最终测试。

匹配消融固定树深8、1200轮及同一五折，分别移除历史特征、本轮神经特征和额外语义特征。语义消融仍保留旧Qwen分支和旧融合分数，只检查额外独立语义向量及语义历史特征，不是从整个系统中删除Qwen。神经消融也保留旧模型分数。移除历史配置删除历史统计、历史相似度、SVD++与两种记忆网络分数。消融是特征组比较，不能把差值解释为单一注意力算子的因果贡献。

审计配对bootstrap按用户重采样1000次，区间是固定选择后的条件差异，不覆盖旧轮选模、新轮结构搜索或全量重训不确定性。额外一个CatBoost随机种子检查只反映树模型随机性，不能当成整套神经网络的多种子复现。

正式最终特征在全部基础模型选轮结束后生成，并登记矩阵及各预测列SHA256。此前66维试验快照与最终时间MF列略有差异，保留为pilot并明确排除正式模型比较，不将其成绩混入正式消融。

## 全量重训与交付

基础神经模型按开发选定轮次在31,900,204条评分上重训，旧Qwen/MF/ALS全量分支复用上一轮已核验产物。测试特征按同名列对齐，使用冻结的五折校正器均值预测，最终裁剪0.5至5.0。校正器继续使用开发折模型，未假称在所有原始评分上重新训练校正层。

新文件 `data/raw/hybrid/test_pairs_predictions_advanced.csv` 保留100,000条userId、movieId、timestamp与原顺序，新增predicted_rating。旧预测保留。测试表没有评分标签，不计算测试RMSE；降低验证/审计误差不保证隐藏测试取得相同幅度改善。
